# Лабораторная работа №2

## Тема
Разработка многостраничного web-сайта с использованием HTML и CSS.

## Описание работы

В рамках лабораторной работы был разработан сайт на тему "Мир автомобилей".

Сайт состоит из трех страниц:

- Главная страница — общая информация;
- Страница моделей — таблица с характеристиками автомобилей;
- Страница контактов — контактная информация.

## Использованные технологии

- HTML5
- CSS3

## Реализованные элементы

В работе использованы:

- блочные и строчные HTML-элементы;
- ссылки между страницами;
- изображения;
- таблица автомобилей;
- отдельный CSS-файл для оформления сайта.
